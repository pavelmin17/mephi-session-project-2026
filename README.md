## Проверки

`verify.sh` проверяет запись каждого разработчика в файлы остальных участников, включая наследование ACL во вложенном каталоге и создание файлов при umask 0777. Для кураторов проверяются чтение и отсутствие права записи, для nobody — отсутствие доступа к каталогу.

`verify-pam.py` вызывает реальную проверку учётной записи через PAM для сервисов login и sshd. Дополнительно библиотека libpwquality проверяет отклонение пароля из 11 символов и принятие сложного пароля из 24 символов. Проверки не изменяют действующие пароли.

Проверки до и после перезагрузки завершились сообщением `ALL CHECKS PASSED`. Результат после перезагрузки сохранён отдельно в `verification-after-reboot.out`; система работает с ядром `6.12.113-1.red80.x86_64`.

После обновления ядра initramfs пересобран в универсальном режиме с драйверами VirtIO. Настройка для последующих обновлений сохраняется в `/etc/dracut.conf.d/50-mephi-virtio.conf`; её копия — `mephi-virtio.conf`. Команды пересборки сохранены в `fix-initramfs.sh`, идентификаторы загрузок — в `boot-check.out`.

## Состав и безопасность публикации

`history.out` объединяет историю интерактивной консоли и выполненные команды автоматизации, записанные Bash xtrace и оформленные встроенной командой history. Секретные операции создания паролей выполнялись с отключённой трассировкой.

Файл `shadow` сохраняет имена учётных записей и параметры срока действия паролей. Действующие хеши заменены строкой `[REDACTED]`, чтобы не публиковать материал для подбора паролей. Это обезличенная копия, а не побайтовая копия `/etc/shadow`.

Пароли, SSH-ключи, токены и приватные резервные копии в репозиторий не включены.

`configure.sh`, `verify.sh` и `collect.sh` содержат команды настройки, проверки и сбора результатов. `configure.sh` предназначен для этой учебной ВМ: он размечает только пустой второй диск `/dev/sdb` размером 8 ГБ. Не запускайте его на другой системе без проверки дисков.
